A mobile robotic platform developed around a hybrid navigation architecture using **ROS 2 Jazzy**.

### Main technologies

`ROS 2` · `Nav2` · `SLAM Toolbox` · `Gazebo Harmonic` · `LiDAR` · `RGB-D` · `IMU` · `BLDC Motors`

### Focus

- Autonomous navigation
- Mapping and localization
- Sensor integration
- Robot simulation
- Hardware/software integration
- Navigation optimization

Development of a low-cost educational robotic system based on **ESP32-S3** and custom electronics.

### Main technologies

`ESP32-S3` · `Custom PCB` · `SG90 Servos` · `3D Printing` · `Embedded C/C++`

### Focus

- Embedded control
- PCB design
- Servo control
- Mechanical integration
- Educational robotics
